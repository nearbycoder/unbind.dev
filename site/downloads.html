macOS

macOS 13 or later

  • Apple siliconARM64 · ZIP ↓
  • Intelx86-64 · ZIP ↓

Unzip, move Unbind.app to Applications, and open it.

Which build and first launch

Open About This Mac from the Apple menu. An Apple Chip uses Apple silicon. An Intel Processor uses the Intel build. Apple’s processor guide

The app bundle uses ad-hoc signing. macOS may request first-launch approval in Privacy & Security. Apple’s opening instructions

Windows

Portable executable

  • x86-64Intel or AMD · ZIP ↓
  • ARM64Arm-based PC · ZIP ↓

Extract the ZIP and open Unbind.exe.

Which build and first launch

Check System type under Settings → System → About. Choose ARM64 for an Arm-based processor, or x86-64 for an x64-based processor. Microsoft’s device guide

The executable has no Windows publisher signature. Windows may show a publisher warning on first launch. The release archive has a signed checksum.

Linux

Ubuntu 24.04 or compatible glibc

  • x86-64Intel or AMD · TAR.GZ ↓
  • ARM64AArch64 · TAR.GZ ↓

Extract the archive and open Unbind/unbind-desktop.

Which build and requirements

Run uname -m. Choose x86-64 for x86_64 or ARM64 for aarch64.

The app needs X11 or Wayland and working Vulkan graphics. Open the included README.txt for Ubuntu library names. Run the archive’s optional ./install.sh to add Unbind to your application menu for your account.

Open invites from your browser

In Unbind, choose Settings → Enable desktop links. When someone sends a link, choose Open in Unbind to review the invite in the app.

Install the CLI

The installers select a build for your computer and check its published SHA-256 before installing.

Share and connect from a terminal ↗

macOS and Linux

curl -fsSL https://unbind.dev/install.sh | sh

The default destination is ~/.local/bin. Add it to your PATH if your shell cannot find unbind.

Windows PowerShell

irm https://unbind.dev/install.ps1 | iex

Open a new terminal after installation if it does not find unbind.

CLI package managers

HomebrewmacOS and Linux

Review the Unbind tap before granting the formula trust.

brew tap nearbycoder/unbind
brew trust --formula nearbycoder/unbind/unbind
brew install nearbycoder/unbind/unbind
ScoopWindows

Add the Unbind bucket in PowerShell.

scoop bucket add unbind https://github.com/nearbycoder/scoop-unbind
scoop install unbind/unbind
WinGetWindows · Local manifest

Download the local manifest bundle. If local manifests are disabled, an administrator can enable them with winget settings --enable LocalManifestFiles.

irm 'https://unbind.dev/downloads/releases/latest/unbind-winget.zip' -OutFile unbind-winget.zip
Expand-Archive unbind-winget.zip -DestinationPath unbind-winget
winget install --manifest .\unbind-winget

    Desktop archives

    Verify the checksum file’s Ed25519 signature with the pinned public key. Then compare the archive’s SHA-256 to the matching entry.

    • Desktop SHA-256 checksums
    • Detached signature
    • Versioned release archive

    Verify an installed CLI

    Run the verifier for your platform. It compares your executable with the current installer checksum. An older version can have a different valid checksum.

    macOS and Linux

    curl -fsSL https://unbind.dev/install.sh | sh -s -- --verify

    Windows PowerShell

    & ([scriptblock]::Create((irm 'https://unbind.dev/install.ps1'))) -Verify
    CLI updates and rollback

    Run unbind update --check to check for a signed release and unbind update to install it. Run unbind rollback to restore the previous executable saved by the updater. For a package-manager installation, update through the same manager.
