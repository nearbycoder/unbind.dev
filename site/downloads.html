Verify your installation

Compare your installed binary with the current published SHA-256 checksum. An older build can have a different checksum.

macOS and Linux

curl -fsSL https://unbind.dev/install.sh | sh -s -- --verify

Windows PowerShell

& ([scriptblock]::Create((irm 'https://unbind.dev/install.ps1'))) -Verify

Run unbind update --check to check for a signed release and unbind rollback to restore the build saved before the last update.
