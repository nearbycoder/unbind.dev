From a local port to a shared service

Share a web app running on port 3000 from your computer.

  1. Create an invite

    On the host, open Share, enter 3000, and select Create invite. Copy the invite or show its QR code.

  2. Connect on the guest

    On the other computer, paste the invite into Connect and set Listen on to 8080. Select Connect.

  3. Open the service

    When the session connects, open http://127.0.0.1:8080 on the guest. Keep Unbind open on both computers while you use the share.

How the connection works

The rendezvous service introduces the computers. After that, service and file traffic flows directly between them.

RendezvousConnection setup
HostLocal service:3000
GuestLocal listener:8080
HTTPS setup Direct encrypted traffic

Create an invite

Unbind registers a short-lived room and gives the host an invite. The secret in the link’s # fragment lets the two clients authenticate the setup messages.

Find a direct path

The clients exchange WebRTC offers and answers over HTTPS. STUN helps each computer discover its UDP address, and ICE tests which pair of addresses can reach each other.

Pass traffic peer to peer

The guest’s local port sends traffic through the encrypted connection to the service on the host. An established tunnel can keep running while rendezvous is unavailable.

Common questions

Find platform setup, network checks, and command examples in the Unbind guide.

Can Unbind connect through double NAT?

It depends on how both networks handle UDP. Unbind tries to find a direct route. A reachable IPv6 path or a UDP mapping can help where supported. The connection fails when a direct UDP path is unavailable. Check the network on both peers.

What can a guest do from the browser?

The join page lets the guest open the invite in Unbind or copy it. The guest runs the desktop app or CLI to connect, then opens a shared web service from its local address.

Can I choose a different port on each computer?

Yes. The host sets the service port, and the guest selects an available local port. To use several ports under one invite, enter the matching route names on both computers.

What happens when the host quits or the network changes?

Quitting the desktop app ends the shares it started. After a network interruption, the guest can reconnect on the same local port, but applications may need to reopen their existing connections.

Can I connect on a LAN without internet access?

Yes. The host can select LAN mode to run rendezvous locally. The guest uses the link from the same reachable private network. Set up a LAN share.
