Quickstart

Install Unbind on both computers. Keep the sharing command running while you use the tunnel.

Share from the host

Run this on the computer where the service is listening on port 3000. Send the printed link to the other computer.

unbind share 3000

Connect from the other computer

Use the link to start a local listener. For a web service, open http://127.0.0.1:8080 on that computer.

unbind connect '<link>' --listen 8080

How it connects

Direct traffic

Unbind exchanges connection details to introduce the computers. The TCP service traffic travels directly between them.

Private links

Anyone with the invite can reach the shared port while the host is running. Send it only to people you want to give access.

Network requirements

Both computers need a working UDP path to each other. Networks that block direct UDP can prevent a connection.

Unbind’s share-and-connect workflow is inspired by Tailcat by Tailscale.
