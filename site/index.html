Features

Share what you’re running

Multiple TCP and UDP ports
Share an app, its API, and a UDP service under one invite. Guests choose the local port for each named service.
SSH from your usual terminal
Use Unbind as an SSH ProxyCommand and connect with your existing SSH client and keys.
Send a file directly
Give one recipient a file invite. Unbind checks the SHA-256 before saving the file.

Choose who gets in

Links, QR codes, and desktop handoff
Copy an invite or show a QR code. Guests with the link handler set up can use Open in Unbind.
Expiring and single-use invites
Set a time limit or admit one guest. Give each guest their own link and revoke it to end their access.
Approve and remember devices
Review guests before they connect. Remember verified devices you want to recognize on future shares.

Run shares your way

Saved profiles and background shares
Save ports and settings in TOML. Run a named share in the background or set it to start at login on supported systems.
Reconnect on the same local port
Unbind retries after a network interruption and keeps your local listener at the same address.
See live connections and traffic
Check who’s connected, how much traffic each connection has carried, and the network path it’s using. JSON output works with scripts.

Connect across networks

Share offline on a LAN
Use built-in connection setup on your local network, or run your own rendezvous server.
Check your network
Run unbind doctor to test connection setup over HTTPS and UDP reachability over IPv4 and IPv6.
Use a router port mapping
Advertise an existing UDP port forward or let Unbind request a temporary mapping on a router that supports PCP.

Install and update with verification

macOS, Windows, and Linux
Get the native app or the command-line client for x86-64 and ARM64.
Checksums and signed releases
Verify your install with SHA-256. The updater checks the release signature and lets you roll back to your previous build.

From local port to shared link

Open Unbind on both computers. Either can share a service or connect to one.

Share from the host

Open Share, enter the port your service is using, and create an invite. Copy the link or show its QR code.

Connect from the guest

Paste the invite in Connect and choose a local port. If you choose 8080, a web service opens at http://127.0.0.1:8080.

Prefer a terminal? Read the CLI quickstart.
